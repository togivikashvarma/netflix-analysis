# Netflix Data Analysis

## Project Overview
This project analyzes the Netflix dataset using Python and Pandas to discover insights about movies and TV shows available on Netflix.

## Dataset
The dataset contains information about Netflix titles including:
- Title
- Type (Movie / TV Show)
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre

Dataset Source: Netflix Titles Dataset

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Objectives
- Analyze number of movies vs TV shows
- Identify top producing countries
- Analyze release year trends
- Find most common genres
- Analyze ratings distribution

## Key Analysis
1. Total number of Movies and TV Shows
2. Top 10 Countries producing Netflix content
3. Content growth over the years
4. Most popular genres
5. Rating distribution

## Sample Visualizations
- Movies vs TV Shows Bar Chart
- Content by Country
- Release Year Trend
- Genre Distribution

## Conclusion
Netflix content has significantly increased after 2015, with the United States producing the most content. Movies dominate the platform compared to TV shows.
